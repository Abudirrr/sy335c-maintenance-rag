# Publication preparation

The application source was imported from the supplied project archive. This edition adds documentation and ignore rules, lists previously implicit runtime dependencies, updates FastAPI template calls to keyword arguments, preserves the submitted query after POST, and replaces overconfident UI text. It also removes pasted instructions after the JSON array in app/testset.json, which previously caused JSONDecodeError, and corrects the evaluation launch command. The retrieval and generation algorithms are unchanged.

Excluded: bundled virtual environment, manufacturer PDFs and derived text/indexes, runtime logs, and original academic DOCX files containing personal identifiers and screenshots. The public technical report summarizes the supplied paper.

The original archive has no dependency lockfile. Syntax validation and focused smoke checks do not substitute for rebuilding the index and running the model with the source manuals. Historical evaluation values are not presented as newly measured results.
